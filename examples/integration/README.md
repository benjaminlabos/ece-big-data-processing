# Entrées synthétiques de démonstration

Ces deux CSV s'utilisent uniquement avec les résultats du module
`imdb_preparation.fixture`, de périmètre `fixture`. Les correspondances Wikipédia
sont fictives et servent à tester le format, les guillemets et le filtrage ;
elles ne doivent pas alimenter une capture réelle ou une collecte d'enrichissement.
La sélection ne résulte d'aucun classement de films.

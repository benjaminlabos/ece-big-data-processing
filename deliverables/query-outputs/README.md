# Sorties intégrales des requêtes

Q1–Q8 et le classement proviennent des Parquet du run vérifié 43125611999,
lot préparé 43093003953. COMPLETE_CSV_EXPORT.json conserve les effectifs,
les SHA-256 et les colonnes encodées en JSON. Les cellules de listes conservent
leurs tableaux JSON ; les CSV sont UTF-8 avec en-tête.

Ces sorties sont complètes, contrairement aux aperçus bornés de query-review.
Pour les télécharger entièrement, utiliser le fichier brut (Raw/Download).
Les paramètres historiques ne sont pas réécrits ; les choix de livraison sont
dans validation/DECISIONS-BINOME.md. Aucun cache Wikimedia ou gros Parquet
n’est ajouté à Git dans ce dossier.
